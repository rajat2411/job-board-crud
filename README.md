# Job Board API

A simple Job Board API built with Node.js, TypeScript, and MySQL.

## Features

- CRUD operations for job postings
- Input validation
- API documentation with Swagger

## Technologies Used

- Node.js
- TypeScript
- Express
- MySQL
- Swagger
- Docker (optional)

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm
